# Reuse disclosure

BuildingOps Autopilot is a new implementation created for the Agents for Humans hackathon. It shares the broad problem domain of facility incident investigation with our earlier exploratory project, but this repository contains a new ticket-based product, UI, data model, durable workflow, policy gateway, verification flow, and Strands integration.

No source files, UI components, orchestration code, or repository history from the earlier project were copied into this implementation. General lessons about facility workflows informed the problem choice. The earlier project can be referenced publicly for transparency; judges should evaluate the work in this repository as the hackathon submission.
