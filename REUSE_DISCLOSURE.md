# Reuse disclosure

BuildingOps Autopilot is a new implementation created for the Agents for Humans hackathon. It shares the broad problem domain of facility incident investigation with our earlier exploratory project, but this repository contains a new ticket-based product, UI, data model, durable workflow, policy gateway, verification flow, and Strands integration.

No source files, UI components, orchestration code, or repository history from the earlier project were copied into this implementation. General lessons about facility workflows—including the usefulness of role-specific evidence gathering—informed the problem choice and specialist-team design. The bounded Strands specialists, typed reports, durable coordinator loop, ticket lifecycle, and UI in this repository were implemented anew for this submission. The earlier project can be referenced publicly for transparency; judges should evaluate the work in this repository as the hackathon submission.
